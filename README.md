# js_railcars_redux

# 🚂 Railcar Rush 3D

A fast-paced **3D lane-switching survival game** built with **Three.js**
🎮✨

------------------------------------------------------------------------

## 🕹️ Gameplay

-   Control your railcar and **avoid incoming trains** 🚧
-   Switch lanes using:
    -   ⬆️ ArrowUp / W
    -   ⬇️ ArrowDown / S
    -   ⬅️ ArrowLeft / A
    -   ➡️ ArrowRight / D
-   You can **ONLY switch lanes when glowing green** 🟢 on a diagonal
    connection!

------------------------------------------------------------------------

## 🎯 Objective

Survive as long as possible and get the **highest score** 💯

------------------------------------------------------------------------

## ⚙️ Features

-   🌍 3D environment using **Three.js**
-   🚄 Procedurally generated trains & track connections
-   🎚️ Difficulty modes:
    -   🟢 Easy
    -   🟡 Medium
    -   🔴 Hard
-   💡 Visual feedback (green glow when switching is allowed)
-   📈 Increasing speed over time for added challenge

------------------------------------------------------------------------

## 🧱 Project Structure

-   `index.html` → Main HTML structure
-   `style.css` → UI & layout styling 🎨
-   `script.js` → Game logic & Three.js rendering 🧠

------------------------------------------------------------------------

## 🚀 How to Run

1.  Download or clone this project
2.  Open `index.html` in your browser 🌐

> No build step required --- it's fully client-side!

------------------------------------------------------------------------

## 🧠 Game Mechanics

-   🚧 Enemies spawn ahead and move toward the player
-   🔀 Connections allow lane switching between tracks
-   ⚠️ Collision with a train = **Game Over 💥**
-   ⚡ Speed gradually increases over time

------------------------------------------------------------------------

## 💥 Game Over

When you crash: - Final score is displayed 📊 - Click **Play Again** to
restart 🔁
